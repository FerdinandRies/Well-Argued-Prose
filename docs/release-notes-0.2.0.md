# JournalProse v0.2.0

## Advanced Scholarly Writing Standards

The Core edition brings together 50 actionable rules for manuscript structure,
foundational reasoning, paragraph progression, academic English, scholarly voice,
literature handling, and argument-preserving compression.

Each rule includes a check, a repair, and an invented worked example. Six workflows
and revision prompts support everyday editing. The local CLI adds 21 surface checks
and an evidence-backed human checklist. Optional Word reading includes body tables.

This release replaces source-specific framing with a general editorial standard.
All public examples are invented. Code remains under MIT; editorial content remains
under CC BY 4.0. Author and maintainer: FerdinandRies.

**Migration:** rule IDs now use `JP2-001` through `JP2-050`, JSON uses schema version 2,
and `checklist` replaces `scorecard`. Remove obsolete files using the migration guide.

**Scope:** pattern checks support human editing. They do not determine AI authorship,
validate arguments, verify publications, or guarantee acceptance. Consult the included
coverage document and the actual test results for the release environment.
