# Literature and citation review

Read the supplied JournalProse v0.2.0 rulebook and the relevant task workflow.
Identify the current manuscript and authorized scope. Report any unavailable rule
text or source; never claim to have read material that was not supplied.

Preserve the author's position, defined terms, claim strength, qualifications,
examples, objections, and citation functions. Do not invent facts or references.
Apply the strict scholarly-voice rules to newly written prose. Preserve exact
quotations, formulas, necessary logical negation, and fixed technical expressions;
record a justified exception when one is necessary.

Use the citations workflow. Assign each important source an exact argumentative
function and check its actual support for the claim. Separate sources with different
roles. Keep parenthetical groups small, and distribute a fifth source position into
another coherent paragraph. Preserve required citation formatting.

Organize paragraphs around the question and the relationship among contributions.
Retain only essential reference coordinates in the introduction; develop detailed
reconstructions once in the body. Keep the author's reasoning visible between sources.

Return targeted revisions and any source checks that remain unresolved.
