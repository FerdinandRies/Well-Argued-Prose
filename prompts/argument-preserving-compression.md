# Argument-preserving compression

Read the supplied JournalProse v0.2.0 rulebook and the relevant task workflow.
Identify the current manuscript and authorized scope. Report any unavailable rule
text or source; never claim to have read material that was not supplied.

Preserve the author's position, defined terms, claim strength, qualifications,
examples, objections, and citation functions. Do not invent facts or references.
Apply the strict scholarly-voice rules to newly written prose. Preserve exact
quotations, formulas, necessary logical negation, and fixed technical expressions;
record a justified exception when one is necessary.

Use the compression workflow. Identify protected inferential steps, concept criteria,
test cases, objection replies, and detailed source reconstructions before cutting.

Cut only repeated definitions, repeated recaps, functionless lists, procedural
roadmaps, synonymous neighboring passages, and abstract-like repetition in the
conclusion. Retain any distinct premise or qualification contained in such passages.
Never combine different literature functions into a citation cluster to save words.

Compare the original and revised reasoning, source roles, terminology, scope,
quantifiers, negation, and modal force. Restore losses. Report an unmet word target
when further cuts would require substantive deletion; do not invent a shortened
version that conceals those losses.

Return the compressed text, the stated counting convention, and a retention record.
